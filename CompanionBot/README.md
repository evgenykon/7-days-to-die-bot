# CompanionBot - AI Companion for 7 Days to Die

Мод добавляет AI-компаньона, который следует за игроком и защищает его от зомби и враждебных животных.

## Требования

- 7 Days to Die 1.0 (stable)
- .NET Framework 4.8 SDK
- Отключённый EAC (Easy Anti-Cheat)

## Установка

1. Запустите `build.bat` для сборки и установки мода
2. Отключите EAC в настройках игры или используйте `-EACLaunchMode=0` при запуске
3. Запустите игру

## Использование

### Спавн компаньона

Откройте консоль (F1) и введите:

```
spawnentity companionbot
```

Для вооружённого компаньона:

```
spawnentity companionbotarmed
```

### Поведение компаньона

- **Следование**: Компаньон следует за ближайшим игроком на расстоянии 3 метра
- **Защита**: Атакует зомби и враждебных животных в радиусе 25 метров
- **Телепортация**: Если игрок уходит дальше 15 метров, компаньон телепортируется к нему
- **Регенерация**: Компаньон восстанавливает здоровье со временем

### Типы компаньонов

| Тип | Здоровье | Оружие | Дальность атаки |
|-----|----------|--------|-----------------|
| `companionbot` | 500 | Руки | 25м |
| `companionbotarmed` | 750 | AK47 | 35м |

## Структура проекта

```
CompanionBot/
├── ModInfo.xml              # Информация о моде
├── Config/
│   └── entityclasses.xml    # Конфигурация NPC
├── Scripts/
│   └── CompanionBot.cs      # C# код мода
├── CompanionBot.csproj      # Проект Visual Studio
└── build.bat                # Скрипт сборки
```

## Настройка

Вы можете изменить параметры компаньона в `Config/entityclasses.xml`:

- `HealthMax` - максимальное здоровье
- `MoveSpeed` - скорость передвижения
- `SightRange` - дальность обнаружения врагов
- `HandItem` - оружие компаньона

## Известные ограничения

- Компаньон не может открывать двери
- Не использует предметы из инвентаря
- Может застревать в сложных локациях
