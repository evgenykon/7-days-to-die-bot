# CompanionBot - AI Companion for 7 Days to Die

Мод добавляет AI-компаньона, который следует за игроком и защищает его от зомби и враждебных животных.

## Требования

- 7 Days to Die 1.0 (stable)
- .NET Framework 4.8 SDK
- Отключённый EAC (Easy Anti-Cheat)

## Настройка пути до игры

Путь до игры задаётся в файле `Directory.Build.props` в корне репозитория (`ai-7d2d/`).

1. Скопируйте шаблон:
   ```
   copy Directory.Build.props.example Directory.Build.props
   ```

2. Откройте `Directory.Build.props` и укажите свой путь:
   ```xml
   <GamePath>D:\Games\7 Days To Die</GamePath>
   ```

Файл `Directory.Build.props` добавлен в `.gitignore` и не коммитится — каждый разработчик указывает свой путь.

## Установка

### Автоматическая установка (рекомендуется)

1. Запустите `install.bat` — скрипт скопирует все файлы мода в директорию игры

### Ручная установка

1. Соберите проект:
   ```
   dotnet build CompanionBot.csproj -c Release
   ```

2. Скопируйте файлы в `%GAME_PATH%\Mods\CompanionBot\`:
   - `ModInfo.xml`
   - `Config\` (вся директория)
   - `bin\Release\net48\CompanionBot.dll`

3. Создайте директорию `Data\` для RAG памяти:
   ```
   mkdir "%GAME_PATH%\Mods\CompanionBot\Data"
   ```

### Отключение EAC

Мод требует отключения Easy Anti-Cheat:

**Вариант 1:** В лаунчере Steam выберите "7 Days to Die - No EAC"

**Вариант 2:** Добавьте параметр запуска в Steam:
```
-EACLaunchMode=0
```

**Вариант 3:** Запустите игру напрямую через `7DaysToDie.exe` (не через лаунчер)

### Запуск игры

1. Запустите игру
2. Откройте консоль (F1)
3. Введите команду спавна компаньона

## Использование

### Спавн компаньона

Откройте консоль (F1) и введите:

```
cb spawn
```

Доступные типы компаньонов:

```
cb spawn male         # Мужской, безоружный (по умолчанию)
cb spawn female       # Женский, безоружный
cb spawn armed        # Мужской, вооружённый AK47
cb spawn armedfemale  # Женский, вооружённый AK47
```

### Команды управления

```
cb follow             # Компаньон следует за вами
cb stay               # Компаньон остаётся на текущем месте
cb guard [radius]     # Компаньон охраняет зону (радиус по умолчанию 10м)
cb dismiss            # Удалить компаньона
cb status             # Показать статус компаньона
cb heal               # Использовать аптечку на компаньоне
cb equip <item>       # Дать предмет/оружие компаньону
cb unequip <slot>     # Снять предмет со слота (weapon/head/chest/legs/feet)
cb inventory          # Показать инвентарь компаньона
cb autopickup [on/off] # Включить/выключить автоподбор лута
cb stats              # Показать боевую статистику
```

### Примеры использования

```
cb spawn armed        # Спавн вооружённого компаньона
cb guard 20           # Охранять зону радиусом 20 метров
cb status             # Проверить здоровье и состояние
cb dismiss            # Удалить компаньона
```

### Поведение компаньона

- **Follow (Следование)**: Компаньон следует за игроком на расстоянии 3 метра
- **Stay (Ожидание)**: Компаньон остаётся на месте, но атакует врагов в радиусе 25м
- **Guard (Охрана)**: Компаньон патрулирует заданную зону и атакует врагов
- **Защита**: Во всех состояниях атакует зомби и враждебных животных
- **Безопасность**: Никогда не атакует игроков, торговцев, NPC и других компаньонов
- **Телепортация**: В режиме Follow телепортируется, если игрок уходит дальше 15м
- **Регенерация**: Компаньон восстанавливает здоровье со временем
- **Сохранение**: Компаньоны сохраняются при выходе из игры и восстанавливаются при входе
- **Мультиплеер**: Каждый игрок может иметь своего компаньона
- **Коммуникация**: Поддерживающие сообщения через LLM (требует LM Studio)

### Боевая система

**Умный выбор целей:**
- Приоритет отдаётся целям, которые атакует игрок
- Учитывается расстояние до цели и уровень её здоровья
- Опасные враги (Feral, Radiated) получают повышенный приоритет

**Тактическое поведение:**
- Отступление при низком здоровье (<30%)
- Избегание стрельбы через игрока (проверка линии огня)
- Перепозиционирование при блокировке линии огня
- Уклонение от атак ближнего боя (стрейф в сторону)

**Ближний бой:**
- Система комбо-атак (сериал ударов)
- Оглушение врагов после 3-х ударов подряд
- Подсчёт комбо-ударов

**Дальний бой:**
- Проверка наличия боеприпасов
- Автоматическое определение необходимости перезарядки
- Переключение на ближний бой при отсутствии патронов

**Обратная связь:**
- Логирование получения урона (обычный/критический)
- Предупреждения при низком здоровье
- Уведомления о комбо-атаках и критических ударах

**Статистика (cb stats):**
- Подсчёт убийств (всего, зомби, животных)
- Учёт нанесённого и полученного урона
- Подсчёт отступлений и избежаний дружественного огня
- Комбо-удары, уклонения, оглушения

**Лечение и экипировка:**
- `cb heal` — использование аптечек из инвентаря игрока
- `cb equip <item>` — передача оружия/предметов компаньону
- `cb unequip <slot>` — снятие экипировки (weapon/head/chest/legs/feet)
- `cb inventory` — просмотр инвентаря компаньона

### Система инвентаря

**Слоты экипировки:**
- Weapon — оружие (ближний бой или дальний бой)
- Head — шлемы, шляпы
- Chest — броня, жилеты
- Legs — штаны, поножи
- Feet — ботинки, обувь

**Управление инвентарём:**
- Ёмкость: 20 предметов (настраивается)
- Автоматическое определение типа предмета при экипировке
- Сохранение инвентаря между сессиями

**Автолечение:**
- Компаньон автоматически использует аптечки при HP < 50%
- Приоритет: FirstAidKit > Bandage > FirstAidBandage
- Аптечки должны быть в инвентаре компаньона

**Управление патронами:**
- Автоматическое использование патронов при стрельбе
- Поддержка типов: 9mm, 7.62mm, shotgun shells
- Проверка наличия патронов перед стрельбой

**Автоподбор лута:**
- `cb autopickup on` — включить подбор лута с убитых врагов
- Шанс подбора: 30% для каждого типа предмета
- Подбираемые предметы: патроны, аптечки, еда, вода
- Требуется свободное место в инвентаре

**Прочность предметов:**
- Оружие теряет прочность при использовании
- Ближний бой: 0.1 прочности за единицу урона
- Дальний бой: 0.5 прочности за выстрел
- Автоматическое снятие сломанных предметов

### Киллер-фича: LLM-коммуникация с RAG

**Особенность:** Компаньон общается с игроком через локальную LLM (LM Studio), создавая уникальный, контекстно-зависимый диалог с поддержкой и уважением.

**Требования:**
- LM Studio (https://lmstudio.ai/)
- Локальная LLM модель с поддержкой OpenAI API
- Модель для embeddings (например, `nomic-embed-text`)

**Настройка LM Studio:**
1. Установите и запустите LM Studio
2. Загрузите модель для чата (например, `llama-3.2-3b-instruct`)
3. Загрузите модель для embeddings (например, `nomic-embed-text-v1.5`)
4. Запустите локальный сервер (по умолчанию `http://localhost:1234`)
5. Отредактируйте `Config/llm_config.json`:
   ```json
   {
     "endpoint": "http://localhost:1234/v1",
     "model": "llama-3.2-3b-instruct",
     "temperature": 0.7,
     "max_tokens": 150,
     "personality": {
       "tone": "supportive, respectful, encouraging",
       "verbosity": "normal",
       "humor": "contextual"
     },
     "rate_limit": {
       "messages_per_minute": 3,
       "cooldown_seconds": 20
     }
   }
   ```

**Автоматические триггеры сообщений:**
- Убийства игрока и компаньона
- Смерть игрока или компаньона
- Начало и конец ночи орды
- Обнаружение редкого лута
- Крафт предметов
- Строительство базы
- Исследование новых локаций
- Начало дня/ночи
- Низкое здоровье (игрока или компаньона)
- Кровавая луна
- Случайные поддерживающие комментарии (idle chatter)
- Диалог с игроком (команды `@companion` или `/companion`)

**RAG (Retrieval-Augmented Generation):**
- Автоматическое индексирование игровых событий
- Векторное хранилище с embeddings
- Семантический поиск релевантных воспоминаний
- Затухание памяти (старые события менее важны)
- Персистентность между сессиями (`Data/memories.json`)

**Примеры диалогов:**
```
[Игрок убил зомби]
Компаньон: "Отличная работа! Ты справился!"

[Началась ночь орды]
Компаньон: "Приготовься, будет жарко! Я рядом!"

[Игрок скрафтил оружие]
Компаньон: "Крутая штука получилась! Теперь мы сильнее!"

[Низкое здоровье игрока]
Компаньон: "Будь осторожен! У тебя мало здоровья, может отступить?"

[Игрок пишет: @companion как дела?]
Компаньон: "Всё отлично! Рад, что мы вместе выживаем!"
```

**Настройка пола и тона:**
- Пол компаньона влияет на формы глаголов (русский язык)
- Настраиваемый тон: поддерживающий, уважительный, ободряющий
- Конфигурация через `llm_config.json`
- Автоматическая гендерно-зависимая речь ("сделал"/"сделала")

**Технические детали:**
- Асинхронные HTTP запросы (не блокируют игровой поток)
- Rate limiting (защита от спама)
- Fallback фразы при недоступности LLM
- Полное логирование для отладки
- Настраиваемая многословность (silent/normal/chatty)

**Игровые команды для диалога:**
```
@companion <сообщение>    — обратиться к компаньону
/companion <сообщение>    — альтернативный синтаксис
```

Компаньон ответит через LLM, учитывая контекст игры и историю взаимодействий из RAG.

## Как работает мод (патчинг)

**Важно:** Мод НЕ модифицирует оригинальные файлы игры. Он использует стандартные механизмы моддинга 7 Days to Die:

### 1. XML Patching

Файл `Config/entityclasses.xml` использует XPath-патчинг для добавления новых сущностей:

```xml
<configs>
    <append xpath="/entity_classes">
        <entity_class name="companionBot">
            <!-- определение компаньона -->
        </entity_class>
    </append>
</configs>
```

Игра автоматически загружает все XML-файлы из `Mods/*/Config/` и применяет патчи к базовым конфигурациям.

### 2. Harmony DLL Injection

Файл `CompanionBot.dll` загружается через HarmonyX (встроен в игру):

- `ModInfo.xml` регистрирует мод
- HarmonyX загружает DLL при старте игры
- `[HarmonyPatch]` атрибуты патчат методы игры в runtime

### 3. Структура файлов после установки

```
%GAME_PATH%/
├── Mods/

### 4. Скрипт install.bat

Скрипт выполняет следующие шаги:

1. Читает `GamePath` из `Directory.Build.props`
2. Создаёт директорию `Mods/CompanionBot/`
3. Копирует `ModInfo.xml`
4. Копирует директорию `Config/` (XML + JSON)
5. Создаёт директорию `Data/` для RAG памяти
6. Копирует скомпилированную DLL из `bin/Release/net48/`

**Запуск:**
```
cd CompanionBot
install.bat
```

### 5. Проверка установки

После установки проверьте наличие файлов:

```
dir "%GAME_PATH%\Mods\CompanionBot"
```

Должны быть:
- `ModInfo.xml`
- `CompanionBot.dll`
- `Config\entityclasses.xml`
- `Config\llm_config.json`
- `Data\` (пустая директория)

## Настройка

Вы можете изменить параметры компаньона в `Config/entityclasses.xml`:

- `HealthMax` - максимальное здоровье
- `MoveSpeed` - скорость передвижения
- `SightRange` - дальность обнаружения врагов
- `HandItem` - оружие компаньона

## Известные ограничения

- Компаньон не может открывать двери
- Не использует предметы из инвентаря
- Может застревать в сложных локациях
